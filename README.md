# FoveaStream - 無邊框四視窗串流播放器 (VLC + Streamlink 架構)

專為多直播同時收看設計的無邊框極簡播放器。整合 Streamlink 串流解析能力與硬體加速播放，支援 4 台直播無縫並行收看。

## ✨ 核心特性

- **無邊框極簡介面 (Borderless Frameless)**：移除 Windows 傳統臃腫標題列與邊框，沉浸式深色視覺。頂部導航列支援任意拖曳移動視窗。
- **四視窗獨立串流 (2x2 Quad Grid)**：
  - 支援 Twitch、YouTube、Kick、AfreecaTV 等所有 Streamlink 支援平台，亦可直接輸入 `.m3u8` 直播源。
  - 各台獨立畫質選單（自動偵測可用畫質，如 1080p60、720p60、480p 等）。
- **痛點解決：智慧音訊管理 (Audio Focus Follow)**：
  - 預設開啟「音訊跟隨焦點」：滑鼠懸停或點選哪一台，該台立刻出聲，其餘自動靜音，徹底告別 4 台聲音混雜的混亂感。
  - 支援 `Alt+1~4` 快速切換獨占音訊，以及 `M` 鍵全體靜音。
- **雙擊放大 / Solo Mode**：
  - 雙擊任意畫面立即全螢幕放大該台，再次雙擊還原 2x2 四分割。
  - 亦可切換 1+3 焦點佈局（1 主畫面 + 3 副畫面）。
- **VLC 外部連動 (Open in VLC)**：
  - 每台畫面均有獨立「錐 VLC」按鈕，點擊即可用系統的 VLC 開啟當前串流。
- **常駐最上層 (Always-on-Top)**：
  - 支援釘選於螢幕最前端（快捷鍵 `T`）。
- **自動記憶與預設組**：
  - 自動記憶上次收看的 4 台網址與音量，下次開啟自動還原。

## ⌨️ 常用快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| `1` ~ `4` | 單獨放大/還原 第 1 ~ 4 台畫面 |
| `Alt` + `1` ~ `4` | 獨占第 1 ~ 4 台音訊（其他台靜音） |
| `Esc` | 退出單台放大，回到 2x2 模式 |
| `M` | 全體靜音 / 解除靜音 |
| `T` | 切換視窗常駐最上層 (Pin) |

## 🚀 啟動方式

1. 雙擊執行目錄下的 `start.bat`，或在終端機執行：
   ```bash
   npm start
   ```
